# EXP-07 — Criar cadência de oportunidade

Pode propor um fluxo com: gatilho, ação, comunicação, tarefa, prazo, condição de avanço, condição de pausa, escalonamento.

```
TRIGGER → CONDIÇÃO → AÇÃO → COMUNICAÇÃO → PRAZO → VERIFICAÇÃO → PRÓXIMA AÇÃO → ESCALONAMENTO
```

O agente deve indicar explicitamente quais etapas dessa cadência exigem julgamento humano (ver `common/skills/gatekeeping.md`) — a cadência é uma proposta de estrutura, não uma automação que o agente executa sozinho.
