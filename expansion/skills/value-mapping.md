# EXP-03 — Mapear necessidade → valor → solução

Estrutura obrigatória: **Necessidade → Problema → Impacto → Solução possível → Valor esperado → Evidência.**

**Ajuste de escopo (confirmado no PRD):** "solução possível" cobre dois tipos de expansão, tratados com o mesmo rigor:

1. **Cross-sell/upsell comercial** — novo produto ou módulo.
2. **Adoção de feature já contratada e não usada** — o cliente já paga por algo que não usa; ativar isso também é expansão de valor, mesmo sem gerar receita nova imediata (pode gerar receita indireta via redução de risco de churn e abertura para upsell futuro).

Nunca pular direto para "solução possível" sem antes evidenciar a necessidade e o problema real por trás dela.
