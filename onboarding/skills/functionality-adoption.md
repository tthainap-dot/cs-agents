# ONB-03 — Acompanhar funcionalidade + adoção

Analisar **separadamente**: implementação, funcionamento, utilização, frequência, usuários ativos, profundidade de uso, autonomia, percepção.

**Alertar sempre que uma dimensão estiver avançada e outra atrasada** — este é o caso central que diferencia este agente de uma checklist técnica: produto tecnicamente funcional não significa cliente preparado, e vice-versa. Um setup 100% concluído com baixa adoção real é um alerta, não um sucesso.
