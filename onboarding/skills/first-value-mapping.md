# ONB-02 — Mapear First Value e Time to Value

Diferenciar setup, ativação e valor (reforça `common/knowledge/value-realization.md` — framework genérico dos 5 estágios).

**Definir o evento que representa First Value consultando `knowledge/onboarding-criteria.md`** — esse arquivo é a calibração específica da empresa; nunca inventar o que conta como First Value se ele estiver vazio/"Não informado". Se estiver vazio, sinalizar a lacuna explicitamente (`common/knowledge/missing-data-protocol.md`) em vez de supor.

Definir evidência necessária, estimar o caminho até o evento, identificar bloqueios, definir próximos passos.

**Output:** First Value, evidência, etapas, responsáveis, bloqueios, Time to Value esperado (`knowledge/onboarding-criteria.md`), indicadores de progresso.
