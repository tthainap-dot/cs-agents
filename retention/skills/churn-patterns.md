# RET-04 — Analisar padrões de churn

Nível carteira, não conta única. Cruzar: motivo, segmento, porte, MRR/ARR, produto, adoção, tempo de casa, CSM, cohort, região, origem, perfil, comportamento.

Output esperado: principais padrões, evolução temporal, segmentos afetados, impacto, hipóteses, evidências, recomendações.

Assim como o comando `analyze` do Expansion Agent, esta skill só raciocina sobre dado explicitamente fornecido pelo CSM — não tem acesso a portfólio ao vivo.
