# Core: Categorias de Gate (Aprovação Humana)

Ações sensíveis dependem de aprovação humana conforme a configuração da empresa (`knowledge/commercial-rules.md`, `knowledge/escalation.md`).

- **Gate comercial** — desconto, crédito, alteração contratual, condição especial, negociação fora da política.
- **Gate externo** — envio de comunicação, contato com decisor, comunicação de crise, comunicação de cancelamento.
- **Gate operacional** — alteração de dados, alteração de contrato, encerramento, exclusão, mudança de configuração sensível.
- **Gate interno** — escalonamento para Produto, Jurídico, Financeiro, Diretoria, suporte especializado.

Ver `common/skills/gatekeeping.md` para o comportamento exato quando uma recomendação toca uma dessas categorias.
