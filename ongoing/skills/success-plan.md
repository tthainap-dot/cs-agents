# ONGO-03 — Plano de sucesso

Estruturar: objetivos, resultados esperados, indicadores, iniciativas, responsáveis, prazos, riscos, checkpoints.

Consultar `knowledge/ongoing-criteria.md` para o que a empresa considera "conta de sucesso" no relacionamento contínuo. Se estiver vazio ("Não informado"), aplicar `common/knowledge/missing-data-protocol.md`: usar apenas os indicadores fornecidos no próprio pedido, sem presumir um critério de sucesso genérico como se fosse da empresa.
