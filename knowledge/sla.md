# SLAs

- **Onboarding:** implantação em até 60 dias.
- **Cross-sell:** contato deve acontecer o mais rápido possível após identificação do sinal.
- **Renovação:** contrato que não renova dentro do mês entra em cancelamento na data de expiração.
- **Novas bases de clientes:** ficam sob responsabilidade do time de CS para negociação, salvo se a base já entrou antes no pipeline de vendas por preenchimento do próprio cliente (nesse caso, segue fluxo de vendas).
